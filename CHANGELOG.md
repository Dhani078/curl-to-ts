v1.0.0 - 2026-11-01

Initial Release
- Tokenizer for POSIX and Windows cURL command lines.
- Automatic TypeScript interface inference from JSON request bodies.
- Native fetch client generator with signal and custom header support.
- Flags: --out, --function-name, --zod, --named-params, --stdin.
