CONTRIBUTING TO curl-to-ts

Guidelines

1. Single Contributor Model
Maintained by Dhani078.

2. Coding Rules
- Pure standard library: No external dependencies.
- Source files strictly under 200 lines of code.
- Node.js >= 20.0.0 LTS.
- Strictly no markdown hash headers and no asterisks in documentation.

3. Testing Requirements
Must pass all test suites validating complex cURL variations (multiline, escaped JSON, basic auth, custom verbs).
